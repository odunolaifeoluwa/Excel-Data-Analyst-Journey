- Lesson 06 — Regional & Product Sales Analysis

- Project Overview

As part of my **Excel Data Analyst Journey**, I built a practical sales analysis project using:

- SUMIF
- SUMIFS
- COUNTIF
- COUNTIFS
- Excel Tables
- Structured References

The goal was to use conditional calculations to answer real-world business questions about sales performance.

- Business Questions

This project answers questions such as:

- Which region generated the highest sales?
- Which product generated the highest sales?
- How many transactions occurred in each region?
- How much did each region generate from each product?
- How many transactions occurred for each region-product combination?

- Key Lessons Learned

This project helped me understand that Excel functions become much more powerful when they are connected to business questions.

I learned that:

SUMIF answers conditional revenue questions using one criterion.
SUMIFS answers conditional revenue questions using multiple criteria.
COUNTIF counts records based on one criterion.
COUNTIFS counts records based on multiple criteria.

I also learned how to combine these functions with Excel Tables and structured references to create reusable analytical reports.

Most importantly, I learned to focus on the question behind the formula rather than simply memorizing the formula itself.
