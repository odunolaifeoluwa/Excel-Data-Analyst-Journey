# Lesson 02 - Excel Tables

## Objective

Learn how to convert raw sales data into an Excel Table and use Excel's built-in features to analyze business data.

---

## Step 1: Converting Raw Data into an Excel Table

I copied the dataset online into the Excel woorkbook.

I selected the entire sales dataset.

Then I clicked:

Insert → Table

I confirmed that "My table has headers" was checked.

Excel converted the data into a structured table with in-built filter.

I named the table created Sales.

---

## Step 2: Revenue Formula Using Structured References

I created a Revenue column.

Instead of using normal cell references, I used structured references.

Formula:

=[@Quantity]\*[@Price]

Excel automatically filled the formula for every row.

---

## Step 3: Sorting and Filtering

Using the filter arrows in the table headers, I:

- Sorted by Revenue (Highest price to Lowest price).
- Filtered to show only Accessories by category.
- Display the sum of Accessories column by clicking on any cell in the table -> click on Table design tab -> checked Total Row box in the Table styles option group.

These features helped answer business questions quickly.

Examples:

- Which product sold the most?
- What Revenue is generated on products under Accessories category?

---

## Step 4: Why Excel Tables Matter

Excel Tables are important because they:

- Expand automatically when new rows are added.
- Automatically copy formulas.
- Make formulas easier to read.
- Reduce mistakes compared to normal ranges.
